# Maze Game

## Overview
This project is a colorful maze game that takes up the full screen. Players navigate through a maze while avoiding traps, all within a time limit. 

## Files
- **src/index.html**: The main HTML file that contains the structure of the game, including the canvas element for rendering.
- **src/style.css**: CSS styles that make the game visually appealing and ensure the canvas takes up the full screen.
- **src/app.js**: The main logic of the game, including maze generation, trap placement, player controls, and time limit implementation.
- **package.json**: Configuration file for npm, listing dependencies and scripts.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd maze-game
   ```
3. Install dependencies (if any):
   ```
   npm install
   ```

## How to Play
1. Open `src/index.html` in a web browser.
2. Use the arrow keys to navigate through the maze.
3. Avoid traps and try to reach the exit before time runs out!
